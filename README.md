# 崩坏：星穹铁道 · 剧情对话整理

《崩坏：星穹铁道》（Honkai: Star Rail）开拓任务与续闻剧情的**中文／英文对照**整理稿，
按版本号归档。每个任务包含区域、登场角色、前置条件、玩家分支选项与逐句台词。

- **33** 个文件，覆盖 **292** 个任务
- **66,493** 条台词（其中 **56,101** 条带中文译文）
- 版本覆盖 1.0 – 4.7（缺 1.1）

## 怎么读

每个任务长这样：

```markdown
## 043　Desolate Depths of Despair　金鼎灵树，穷途梼杌

> 世界：The Xianzhou Luofu　|　区域：Artisanship Commission (Location)　|　角色：...

### Pass through the Artisanship Commission's shortcut and head to the Alchemy Commission

> *任务概要*

*(舞台提示 / 动作描述)*

- ▸ 玩家选项

**March 7th:** 英文台词

> **三月七：**中文台词
```

段落约定：

| Markdown | 含义 |
| --- | --- |
| `#` / `##` / `###` | 章 / 任务 / 任务目标 |
| `> 世界：…` | 任务元数据（区域、角色、前置） |
| `> *斜体*` | 任务概要 |
| `*(括号)*` | 舞台提示、动作、过场描述 |
| `- ▸` | 玩家可选项 |
| `**人名:**` | 英文台词说话人 |
| `> **人名：**` | 紧随其后的中文译文 |
| `【游戏内短信】` | 短信、书籍、终端等非对话文本 |

英文台词与中文译文**交替出现**，中文以引用块形式紧跟在对应的英文行下方。

## 目录

```
版本/   主线（开拓任务），按版本号命名
续闻/   续闻 / 同行类剧情，按版本号命名
tools/  docx → Markdown 转换脚本
```

每个剧情同时保留两种格式：`.md`（可直接阅读、可 diff）与 `.docx`（原始排版，
**含版本主视觉图**）。图片没有抽出来，只在 docx 里。

## 重新生成 Markdown

`.md` 全部由同目录的 `.docx` 转换而来，脚本只依赖 Python 标准库：

```bash
python3 tools/docx2md.py            # 转换全部
python3 tools/docx2md.py 版本/1.2_云树百丈蔽重楼.docx   # 只转一个
```

脚本按 docx 里的自定义样式（`Meta` / `Line` / `Zh` / `Choice` / `Scene` / `Note`）
重新映射标题层级与段落类型，不做启发式猜测。改完 docx 后重跑即可。
